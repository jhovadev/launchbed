# F1.6D — Release optimization, privacy and native APK checks

Incremental on F1.6C. No i18n, new addons, Android Studio, Gradle version change, or phone actions.

## Changes

- Generated apps use AGP 9.3+ `optimization { enable = true }` for release builds, which enables R8 code and resource optimization. The debug build configuration is unchanged.
- The conservative template default is `android:allowBackup="false"` plus `fullBackupContent` for Android 11- and `dataExtractionRules` for Android 12+ with explicit cloud and device-transfer exclusions. This protects privacy by default but sacrifices automatic recovery of local-only notes after uninstall/reset.
- `scripts/release/native-apk.mjs` inspects *actual APK* central directories, `.so` ELF `PT_LOAD` alignment and uncompressed ZIP alignment for 16 KB. The parser deliberately rejects malformed/unsupported archives; test cases cover malformed ELF and offset alignment. Absence of native `.so` is verified from the APK, not guessed from source files.
- `scripts/release-audit.ts build --all` extracts each generated preset into a fixed ignored directory, invokes `assembleRelease` and `lintRelease`, examines unsigned APKs, and writes `build/release-audit/report.json`. No device, emulator, SDK installation or signing. Gradle may download normal declared dependencies.
- `release-check` requires a matching source fingerprint and four successful release audits before accepting R8/static native evidence. Device instrumentation remains a separate BLOCKED gate.

## Commands

```sh
just release-parser-test
just check
just android-runtime-compile
just release-audit
just release-check  # exit 78 BLOCKED until instrumented tests execute on a device
```

## Not guaranteed

Unsigned APK release build != production-signing readiness. Source-only checks != transitive native compliance. Static native checks != device runtime with a 16 KB kernel. Explicit backup exclusions != verified OEM policy; review cross-platform migration and user data recovery. No Play Store/privacy-policy certification. Never report a release PASS without instrumented tests and all other required gates.

Official background: https://developer.android.com/topic/performance/app-optimization/enable-app-optimization , https://developer.android.com/identity/data/autobackup , https://developer.android.com/guide/practices/page-sizes .
