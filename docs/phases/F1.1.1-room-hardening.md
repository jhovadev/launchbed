## Version diagnosis

- KSP 2.3.12 does not have a matching Compose compiler plugin.
- Latest common Kotlin version for KSP and Compose compiler is 2.3.10.
- Room 2.8.5 builds with KSP 2.3.10 and Kotlin 2.3.10.
- AGP 9.5.1 supports KGP 2.2.10+, so 2.3.10 is valid.
- Template therefore uses Kotlin/KGP/KSP/Compose 2.3.10.
