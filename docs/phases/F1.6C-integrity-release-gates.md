# F1.6C — Integrity & Release Gates

This patch provides source ZIP integrity validation, report classifications, and historical patch replay without changing generated Android Kotlin code or dependencies.

## Delivered

- `scripts/integrity-check.ts`: four-preset deterministic ZIP / safety / wrapper check; `--release` checks runtime+benchmark evidence.
- `scripts/integrity/gates.mjs`: pure evidence classifiers and path/checksum validation.
- `scripts/integrity/gates.node.test.mjs`: seven Node regression tests, including a missing-device-evidence scenario and a failing-unit-test scenario.
- `scripts/integrity/patch-chain.json`: SHA-256 manifest for F1.0–F1.6B (excluding F1.6C to avoid self-referential hashes).
- `scripts/integrity/patch-replay.mjs`: isolated Git clone and true patch application; content parity of unchanged source files (PowerShell/batch EOL normalization only).
- just recipes, package scripts and a lightweight CI source integrity gate.

## Verification contract

`just integrity-check` may PASS with no SDK. `just release-check` must remain BLOCKED in the absence of executed instrumentation. Source ZIP checks do not replace Android builds, device tests, release signing, dependency CVE scans or 16 KB native ABI checks. No timing thresholds are introduced to CI. See `docs/integrity.md`.

## Expected post-apply commands

```sh
node --test scripts/integrity/gates.node.test.mjs
bun run typecheck
bun test packages tests
bun run check:astro
bun run templates:check
bun run build
just integrity-check
just patch-replay
just release-check  # may exit 78 BLOCKED until instrumented tests are executed
```
